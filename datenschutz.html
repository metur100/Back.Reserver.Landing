Diese Website

Diese Landingpage wird über GitHub Pages bereitgestellt. Sie verwendet keine Cookies, kein Tracking und keine Analysewerkzeuge. Schriftarten werden lokal ausgeliefert; es werden keine Inhalte von Drittanbietern nachgeladen. Beim Aufruf verarbeitet der Hosting-Anbieter technisch notwendige Verbindungsdaten (z. B. IP-Adresse) in Server-Logs.

Damit die kurze Einstiegsanimation nur einmal pro Sitzung erscheint, speichert die Seite einen Hinweis im Sitzungsspeicher Ihres Browsers (sessionStorage). Dieser Eintrag verlässt Ihr Gerät nicht und wird beim Schließen des Tabs gelöscht.

Die Anwendung BackReserve

Für die Bestell- und Verwaltungsfunktionen gilt eine eigene Datenschutzerklärung der jeweiligen Bäckerei bzw. von BackReserve. Bei einer Reservierung werden nur die für die Abholung nötigen Daten verarbeitet (Vorname, E-Mail-Adresse, optional Nachname und Telefonnummer).
